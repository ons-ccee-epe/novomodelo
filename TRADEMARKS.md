# Use of the Cobre name and logo

The Cobre source code is licensed under the Apache License 2.0 (`LICENSE`).
That license does not grant rights to the project's name or logo (section 6).
This page states how they may be used.

"Cobre", the Cobre logo and the Cobre icon (`assets/cobre-*.svg`) identify this
project and the releases published from <https://github.com/cobre-rs>.

You may use the name to refer to the project factually, for example "based on
Cobre", "a fork of Cobre", or "reads Cobre case directories", in documentation,
papers, talks and package descriptions.

A modified version that you distribute, including a fork, must use a different
name and must not use the Cobre logo or icon as its own. It must not suggest
that the Cobre project endorses it or is affiliated with it unless the
maintainers have agreed to that in writing.

For anything not covered here, open an issue at
<https://github.com/cobre-rs/cobre/issues>.
